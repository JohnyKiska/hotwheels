## Назначение

Парсер принимает сохранённую HTML-страницу отдельной карточки модели All Hot Wheels и возвращает одну candidate-запись для ручной проверки. Он не загружает страницы по сети, не обращается к БД и не записывает данные в каталог.

Endpoint: `POST /imports/all-hot-wheels/html-preview`.

## Семантические ограничения

- `special_label` сохраняет термин источника. `chase` не превращается в TH или STH.
- Категория, название серии, позиция в серии и special label остаются отдельными полями.
- `Mainline #` не выводится из Fandom `Col.#`. Это независимые поля двух источников.
- Отсутствующее или отображённое как `-` значение не подменяется догадкой; исходное значение остаётся в `source_values`.
- Самостоятельное положительное значение `Series index` не получает выдуманный знаменатель и не считается `mainline_number`.
- Некорректная дробь позиции серии (например, `0/5`) сохраняется как raw value и добавляется в `issues` с предупреждением.
- Для индивидуальной карточки `mainline_total` остаётся `null`: годовой знаменатель берётся только из отдельного подтверждённого источника.
- Парсер не создаёт Casting/Release и не объединяет записи.

## Известные ограничения первого среза

- Парсер рассчитан на текущую DOM-структуру сохранённых страниц All Hot Wheels. Изменение разметки сайта потребует обновления parser и fixtures.
- Категория на первом этапе определяется по сегменту canonical URL; для известных категорий добавлены человекочитаемые подписи, неизвестный slug сохраняется.
- Цвета извлекаются из видимых DOM-чипов с сохранением компонента (`body`, `interior`, `base`, `window`). Атрибуты `color`, `detailed` и `source` остаются отдельными; исходный атрибут `premium` сохраняется в поле `finish`. Чипы одной детали объединяются в одну структуру.
- Если сайт скрывает часть блока для гостя, парсер не пытается восстановить скрытые значения из маркетингового текста или других карточек.
- Реальные HTML-файлы используются только для локальной проверки и не должны попадать в репозиторий. В CI применяются синтетические fixtures.
- Synthetic parser/API tests покрывают компоненты цветов, provenance, самостоятельный индекс `95` и предупреждение для `0/5`. GitHub Actions run #150 на документационном follow-up подтвердил: `pytest` — 147 passed, 8 warnings; `browser-e2e` — success.
- В текущем run изучены реальные HTML BL018, HTF33, HYW28, JBC25, JKF45 и JRP31 из ветки `feature/scheduled-market-data` на уровне структуры и подписанных значений. Это source-level аудит, не прямой запуск committed Python parser. Реальные HTML и изображения в PR не добавляются.
