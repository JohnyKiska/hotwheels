# All Hot Wheels HTML Importer

**Статус:** первый read-only parser добавлен в Draft PR #74; synthetic CI run #140 прошёл (`pytest`: 145 passed, `browser-e2e`: success). Прямой запуск committed parser на четырёх реальных HTML-файлах ещё требуется подтвердить.

## Назначение

Парсер принимает сохранённую HTML-страницу отдельной карточки модели All Hot Wheels и возвращает одну candidate-запись для ручной проверки. Он не загружает страницы по сети, не обращается к БД и не записывает данные в каталог.

Endpoint: `POST /imports/all-hot-wheels/html-preview`.

## Извлекаемые поля

| Поле preview | Поле/элемент источника | Примечание |
|---|---|---|
| `toy_number` | `SKU` | Проверяется формат из пяти буквенно-цифровых символов |
| `name` | `h1` | Название модели как на странице |
| `release_year` | `Release year` | Сверяется с optional `expected_year` |
| `category` | сегмент canonical URL | Сохраняется также исходный `category_slug` |
| `special_label` | primary badge | Исходная метка без нормализации, например `treasure hunt` или `chase` |
| `scale` | `Scale` | Например, `1/64` |
| `base_material` | `Base material` | Например, `Plastic` или `Metal` |
| `series_name` | series badge | Текст источника |
| `series_index/series_total` | `Series index` | Отдельно от Mainline number |
| `mainline_number` | `Mainline #` | Читается только из явно подписанного поля; `-` становится null |
| `wheels` | Wheels | Список code/name |
| `colors` | Colors | Список attribute/value из доступного блока |
| `tags` | Tags | Список текстовых тегов |
| `source_url` | canonical link | URL страницы-источника |
| `source_fields` | parser mapping | Подсказка происхождения каждого поля |

## Семантические ограничения

- `special_label` сохраняет термин источника. `chase` не превращается в TH или STH.
- Категория, название серии, позиция в серии и special label остаются отдельными полями.
- `Mainline #` не выводится из Fandom `Col.#`. Это независимые поля двух источников.
- Отсутствующее или отображённое как `-` значение не подменяется догадкой.
- Парсер не создаёт Casting/Release и не объединяет записи.

## Известные ограничения первого среза

- Парсер рассчитан на текущую DOM-структуру сохранённых страниц All Hot Wheels. Изменение разметки сайта потребует обновления parser и fixtures.
- Категория на первом этапе определяется по сегменту canonical URL; для известных категорий добавлены человекочитаемые подписи, неизвестный slug сохраняется.
- Цвета извлекаются из видимых DOM-чипов. Если сайт скрывает часть блока для гостя, парсер не пытается восстановить скрытые значения из маркетингового текста или других карточек.
- Реальные HTML-файлы используются только для локальной проверки и не должны попадать в репозиторий. В CI применяются синтетические fixtures.
- Добавлены synthetic parser/API tests. Не объявлять парсер проверенным на реальных карточках, пока локальный прогон на JBC25, GJJ06, CKJ44 и JHW68 не выполнен и CI на актуальном commit не завершился успешно.
