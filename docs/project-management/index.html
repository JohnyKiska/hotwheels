🔎 Карточка элемента

Выбери элемент дерева, чтобы посмотреть подробности и изменить его.
Как пользоваться: выбери элемент слева → измени статус и описание справа → нажми «Сохранить». Изменения автоматически сохраняются в этом браузере. Для переноса на другой компьютер используй «Экспорт JSON», а затем «Импорт JSON». Сам HTML-файл является отдельным приложением, сервер не нужен.
