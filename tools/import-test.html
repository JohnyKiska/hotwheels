Hot Wheels Garage · Тест импорта v0.2.0

Проверочная страница: сопоставляет сохранённые HTML-страницы All Hot Wheels с записями collection.json. Исходный файл не меняется автоматически — результат можно скачать отдельно после проверки.

1. Выбери файлы

Файл каталога из репозитория. Обрабатывается локально в браузере.

Выбери одну или несколько страниц, сохранённых через браузер. Можно начать с четырёх тестовых моделей.

Ожидаются файлы.

2. Результаты сопоставления

Поля заполняются только если найдены в HTML и пока пусты в каталоге. Существующие значения, статус, цена и комментарий не перезаписываются. Все извлечённые детали записываются в объект details вместе с источником.

3. Что важно знать

  • v0.2.0 обрабатывает только выбранные HTML-файлы; папка ALLHW используется как архив, страница не читает её автоматически.
  • Страницы All Hot Wheels сериализуют часть данных в Next.js payload, поэтому результат зависит от того, какие значения реально присутствуют в сохранённой странице.
  • Если поле не извлечено, это не доказывает, что источник его не содержит: формат может требовать отдельного правила парсинга.
  • Перед массовым импортом нужно проверить точность на образцах. Не загружай результат в основную ветку, пока не проверены отчёт и JSON.

Локальная обработка: выбранные файлы не отправляются на сервер этой страницы. Сохрани исходный JSON перед экспериментами.
