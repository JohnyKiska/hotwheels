Hot Wheels Garage · Тест импорта v0.7.0

Проверочная страница: сопоставляет сохранённые HTML-страницы All Hot Wheels с записями collection.json. Повторные SKU пропускаются, ручные статусы можно восстановить из предыдущего черновика. Исходный файл не меняется автоматически — результат можно скачать отдельно после проверки.

1. Выбери файлы

Файл каталога из репозитория. Обрабатывается локально в браузере.

Выбери одну или несколько страниц, сохранённых через браузер. Можно начать с четырёх тестовых моделей.

Загрузи прошлый catalog-schema-draft.json, чтобы сохранить ручные статусы и заметки при повторном импорте.

Ожидаются файлы.

2. Результаты сопоставления

Поля заполняются только если найдены в HTML и пока пусты в каталоге. Существующие значения, статус, цена и комментарий не перезаписываются. Новая классификация сегмент / линейка / тематическая серия сохраняется в details для проверки, не заменяя старые поля каталога. Год и прежние значения заполняются только при пустых полях. Все извлечённые детали записываются в объект details вместе с источником в details.sourceUrl.

3. Визуальная проверка каждой машинки

Карточки ниже показывают, что парсер реально извлёк из каждой HTML-страницы. Прочерки означают, что значение не найдено — это не обязательно означает, что его нет на сайте. Сравни карточку с исходной страницей, прежде чем доверять импорту.

Сначала выбери файлы и нажми «Проверить и сопоставить».

4. Что важно знать

  • v0.7.0 исправляет перенос редкости и сохраняет масштаб; пропускает повторные SKU в одном запуске; может восстановить ручные статусы/заметки из предыдущего черновика. Обрабатывает только выбранные HTML-файлы; папка ALLHW используется как архив, страница не читает её автоматически.
  • Страницы All Hot Wheels сериализуют часть данных в Next.js payload, поэтому результат зависит от того, какие значения реально присутствуют в сохранённой странице.
  • Если поле не извлечено, это не доказывает, что источник его не содержит: формат может требовать отдельного правила парсинга.
  • Перед массовым импортом нужно проверить точность на образцах. Не загружай результат в основную ветку, пока не проверены отчёт и JSON.

Локальная обработка: выбранные файлы не отправляются на сервер этой страницы. Сохрани исходный JSON перед экспериментами.
