# Catalog image storage

This directory is reserved for first-party photographs and image files that HW Catalog is permitted to store and redistribute.

## Rules
- Do not copy third-party images unless the license or explicit permission allows local storage and the intended use.
- Keep original files unchanged; generate thumbnails/optimized derivatives separately.
- Register each stored asset in `../data/images.json` with its stable asset ID, file path, checksum, creator/source, rights basis, and review status.
- Link image assets to release/variant IDs, not only to model names.
- External image URLs used for research belong in the research/reference manifest and are not first-party assets.

No image files are bundled here yet.
