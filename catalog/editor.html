Создать или изменить элемент

ID элемента стабилен. Переименование меняет название, но не создаёт новую запись. Для неоднозначных одноимённых записей сначала выбери нужную строку.

Связи и перемещение

Выбери один или несколько элементов слева, затем родителя. Добавление новой связи не удаляет другие размещения. Чтобы именно переместить элемент, сначала добавь новую связь, затем убери старую в блоке «Текущие связи».

Циклические связи блокируются. Удаление связи не удаляет сам элемент или исходные данные.

Элементы каталога

Черновик и применённая рабочая версия сохраняются только в localStorage этого браузера. Экспорт JSON создаёт файл для ручного сохранения в репозитории. Эта страница пока не записывает изменения обратно в GitHub и не изменяет collection.json.
