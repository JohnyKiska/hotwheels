Создать или изменить элемент

ID элемента стабилен. Переименование меняет название, но не создаёт новую запись. Для неоднозначных одноимённых записей сначала выбери нужную строку.

Связи и перемещение

Выбери элементы в списке справа, начни вводить название места назначения и выбери подходящий вариант из подсказок. Перемещение заменяет их прежнее родительское размещение; сами элементы и их ID сохраняются. Для нескольких элементов операция выполняется сразу для всех выбранных.

Циклические связи блокируются. Удаление связи не удаляет сам элемент или исходные данные.
